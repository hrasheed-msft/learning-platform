## Pronunciation guide toggle

Every card, large Arabic line and verse writes its transliteration inside an element with the class `nq-tr` (see
`nuraniyyah-html.ts`). `UnitViewer.tsx` shows a **Show pronunciation guide** switch whenever a unit contains `nq-tr`, and
hides `.nq-tr` through CSS (`[data-transliterations='off'] .unit-content .nq-tr`). It is **off by default**; the choice is kept
in `localStorage` under `nuraniyyah-show-transliterations` (`useNuraniyyahTransliterations`). The 🔊 icon of a tappable card
stays visible while the guide is hidden. Transliterations written inline in tables and explanations are not hidden.

## Audio model

* Clip URL: `/audio/nuraniyyah/cdNN-CCC.mp3`, NN = CD lesson (= book lesson), CCC = clip number. Clip numbers are 0-based
  positions in the track, and the split file `NNN.mp3` is clip + 1.
* **The CD reads the book in order, so every cell or word of the PDF has a clip; the plan is built from the sequence,
  not from isolated Whisper matches.** Whisper labels are only used to cross-check.
* Letter-by-letter lessons are read in groups of 5 clips (spelled fatḥah, spelled kasrah, short pair, spelled ḍammah,
  combined triple), then single combined clips. The card audio is the combined clip. Positions used:
  * L1: letters at clip `3+k` (30 cells). L3: `2+k` (15 cells).
  * L4: spelled letters at `10+5g` (8 groups: أ ه ع ح غ خ ق ك), singles at `46+k` (20 letters).
  * L5: spelled at `10+5g` (م ب و ف ث ذ), singles at `36+k`, hamza group at 61.
  * L7: `4+k` for the first 14 letters (the CD stops there); the five cells at the foot of the page (إِ هِ وُ هُ ءُ with small
    yā / wāw) are clips 18–22.
  * L8 madd: spelled at `7+5g` (11 letters), singles 58–72, then ن at 77 and و at 82.
    L8 līn: groups of 3 from clip 84 (10 letters), singles 114–128, then و/ه/ي at 131, 134, 137.
* **L2:** track 003 has 2 intro clips, one clip per cell and a closing jingle, so cell `k` is clip `k+2` for all 127 cells
  (`build_audio_plan.py` refuses to run if the counts differ). Counting clips is how a missing cell was found: the book has
  six cells on row 3 of page 7 (`كب كب كا كا بكت تكث`) and the first transcription had five.
* **Exercise words (L6 track 007, L9 track 010, L11 track 013):** a word the teacher spells out takes `2n − 1` clips (n =
  letters-with-ḥarakah; each letter spelled, then a reading of everything so far) and the **last** clip reads the whole
  word; any other word is one clip. `structure.py` walks the track word by word with that rule. The walk ends exactly on the
  last clip before the jingle in L6 (149) and L9 (254), which proves the word list and the clip sequence agree. Whisper
  alone picked the partial reading (e.g. "humaza") instead of the whole word (e.g. "humazatin") for 9 words.
* L10 (sukūn): each letter group starts with two consecutive long clips (≥ 2.3 s); the ḍammah spell is the last long clip.
  The combined reading is one clip or the short tail clips joined by ffmpeg into `cd10-grp-NN.mp3` (16 groups).
* Whisper labels are approximate (`small`, int8, CPU, ~1 hour for all tracks); cached in `tools/nuraniyyah-audio/work/*.json`
  (gitignored). `relabel.py` re-transcribes chosen clips one by one with a vocabulary prompt (`work/NNN.v2.json`).

### Why lesson coverage used to be low (and what was wrong)

The first plan accepted only clips whose Whisper label looked like the word. Whisper garbles short clips (empty labels,
"باااا" hallucinations, ذ heard as د), so about a third of the words had no clip. The audit found three real causes
besides ASR noise: two cells/words missing from the transcription (L2 `كب`, L9 `جِيءَ`, and the L7 cell `وُ`), one pair of
words in the wrong order (L9 `يَتِيمًا` before `يَسِيرًا`), and the L9 extra words (`مَوَازِينُهُ`, `يَوْمَئِذٍ`) not being aligned.
What remains without audio does not exist on the CD (L7 last 14 letters, L10 qalqalah cards) or is not in the book (L1 extras).

### Regenerating audio

From `backend/`, with `$env:TS_NODE_COMPILER_OPTIONS='{"module":"commonjs","moduleResolution":"node"}'`:

1. `npx ts-node --transpile-only ../tools/nuraniyyah-audio/export-content.ts`
2. (optional) `python ..\tools\nuraniyyah-audio\relabel.py 010:9-35` for clips with poor labels
3. `python ..\tools\nuraniyyah-audio\build_audio_plan.py` (writes `nuraniyyah-audio.ts`; `plan-report.txt` lists every word)
4. Repeat step 1, then `python ..\tools\nuraniyyah-audio\coverage.py` (unused clips) and `publish_clips.py`

Python needs: PyMuPDF (`fitz`), imageio-ffmpeg, numpy, scipy, matplotlib, faster-whisper. Set `PYTHONIOENCODING=utf-8`
on Windows for Arabic output.

## Known gaps and risks

* **Matched clips have not been auditioned.** Spot-check cards after any regeneration.
* **Vowel marks were read from page images** and need proofreading, especially some `ء`/`أ` cells and the words
  `رَضُوا`, `عَائِلًا`, `سَلَمٌ`.
* Shaddah, ghunnah, madd lāzim, noon/meem sākinah and summary lessons were dropped because the new PDFs end at page 19.
  If later pages are supplied, the rest of track 013 and tracks 014–018 are ready to be mapped.
* `.github/workflows/run-seed.yml` does not offer `seed-nuraniyyah`; that change is in local-only commit `feb36ab`
  (the `hrasheed-msft` gh account lacks the `workflow` scope). Not required: `seed-maktab-program` seeds the course first.
* `lint-backend` in CI fails on repo-wide pre-existing problems (970; test files are outside tsconfig). It is not a deploy gate.
* One backend integration test needs Postgres at `localhost:5432` and fails without it (pre-existing).

## Deploying and seeding

* Merge to `main` triggers CI/CD (backend → ACR / Container App; frontend → Static Web App
  `swa-islamic-learning-34odstpjgaabg`, `icy-field-0f8ffd710.7.azurestaticapps.net`). Azure CLI must be logged in as
  `hassan.rasheed1@live.com`. See `.squad/skills/production-deploy/SKILL.md`.
* Seed production: `gh workflow run run-seed.yml --ref main -f seed=seed-maktab-program` (use the `hrasheed-msft` gh account;
  `gh auth switch -u hrasheed-msft`). The seed is idempotent and removes lessons no longer in the course.
* The lesson HTML lives in the database, so **content changes (the `nq-tr` markup, new cells, new clips) only reach
  production after the seed has run**; the toggle button appears only for units whose HTML contains `nq-tr`.
* Prisma `units` columns are camelCase (`"orderIndex"`, `"courseId"`).
